# 🎮 Concordia — Versión para Amigos

Aplicación minimalista y ligera de chat de voz y pantalla compartida a 60 FPS con supresión de ruido por IA.

---

## 🚀 ¿Cómo unirte a la llamada?

### 1. Descargar la carpeta
Haz clic en el botón verde **Code** arriba a la derecha y selecciona **Download ZIP** (o clona el repositorio). Descomprime el archivo en tu computadora.

### 2. Iniciar por primera vez
Abre la carpeta y haz doble clic en:
```bat
instalar_y_jugar.bat
```
> **Nota:** La primera vez verificará tu instalación de Python, instalará las librerías de audio y descargará automáticamente los componentes de streaming de video de alta velocidad (FFmpeg y MPV).

### 3. Conectarse a la sala
1. Elige tu foto de perfil (opcional).
2. Escribe tu **Nombre de usuario**.
3. Ingresa la **IP del Host** que te pasó tu amigo (o déjala vacía / 127.0.0.1 si eres tú quien crea la sala).
4. Haz clic en **"Conectar"** (o "Crear Sala" si eres el Host).

---

## 💡 Tip para abrir sin consola
Una vez configurado por primera vez, puedes abrir la aplicación con un doble clic en:
```
Abrir Discord.vbs
```
Esto iniciará Concordia directamente en segundo plano sin mostrar ninguna ventana de consola negra.
